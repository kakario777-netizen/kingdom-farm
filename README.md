# 말랑 왕국

옛 iOS 게임 **위룰(We Rule)** 을 바탕으로 만드는 쿠키런 톤의 싱글 왕국 육성 게임.

- 게임 본체: `game/game.html` (이 파일 하나에 게임 전부)
- `main`에 올리면 GitHub Actions가 자동으로 APK를 만들어 **Releases**에 올림
- 최신 APK: 저장소 오른쪽 **Releases → 최신 빌드 → malang-kingdom.apk**

## 시간
- 개발 중: `DEV = true`, 기본 20배속(게임 1시간 = 실제 3분), 테스트 버튼 있음
- 최종 빌드: `game/game.html`의 `DEV = false` 한 줄만 바꾸면 리얼타임

## 방향
- 이웃 왕국 없이, 내 왕국을 알뜰하게 채우는 데 집중
